## 🚀 Featured Project

### 🛒 Localii: Hyperlocal Multi-Vendor Commerce *(in progress)*

A quick-commerce marketplace where orders are picked from a neighbourhood vendor's own store. No dark stores, no warehouses. It has four actors: **Customer · Vendor · Delivery Partner · Admin**.

**v1 shipped** in FastAPI + PostgreSQL + Redis + Docker. **Now rebuilding it in Java Spring Boot** (monolith first, microservices later).

What makes it more than a CRUD app:
- 📐 **Designed before coding.** I did the full HLD for multi-city scale (~1M users, ~10K vendors, 99.9% availability target)
- ⚡ **<300 ms browsing** through caching. Stock is eventually consistent while browsing but **strongly consistent at checkout** (atomic order + stock + payment)
- 💳 **Payment is captured only after the vendor accepts**, so customers are never charged for rejected orders
- 🔐 **Security by design**: JWT access + refresh tokens, RBAC, rate limiting, audit logs, encrypted PII, and PCI-DSS via gateway tokenization
- 🚚 **Auto-assigns the nearest available delivery partner**

`Java` `Spring Boot` `FastAPI` `PostgreSQL` `Redis` `Docker`
